- Every analysis saved to a searchable, shareable library
- AI-generated plain-language palette descriptions for client presentations
- Free tier + paid plans for high-volume professional work

`Next.js` `NestJS` `TypeScript` `PostgreSQL` `Prisma` `Stripe`
